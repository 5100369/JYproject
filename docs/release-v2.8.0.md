# VideoMatrix 2.8.0

发布日期：2026-10-13

## 新增功能

- 在线更新：启动自动检查、空闲自动下载，手动暂停 / 断点续传，查看更新内容，用户确认后安装。不会强制重启。
- 三个预设公共加速源 + GitHub 原站，可补充预设、配置自定义加速和国内副本，最多 8 个源，失败回退。
- 手动检测下载源连通性和 HTTP 响应时间，可排序后保存；只读取文件头及小清单，不下载整包。
- 开发版更新演练：正常下载 / 暂停续传、主源失败回退、签名错误、文件校验错误。仅使用本地随机数据，不安装、不改正式配置。

## 修复与保护

- 清单 404 与网络故障分开提示；识别拦截页和签名失败。
- Ed25519 签名清单、包大小和 SHA256 校验；异常 Range 不拼接错误数据，磁盘余量不足时不下载。
- 混剪 / 排队 / 压测 / 停止清理优先：忙时不安装，下载与校验暂停；已有视频、素材和配置保留。
- 更新缓存、设置和任务状态检测与原混剪流程隔离，不新增整片转码或逐帧处理。

## 使用说明及限制

- 旧版没有更新器，首次仍需手动安装带更新功能的版本。
- Windows 确认后打开 NSIS 安装向导；Mac 打开 DMG 后手动安装。Mac 未 Apple 开发者签名及公证，仍需实机验证。
- 旧任务的续跑记录不能跨后端重启恢复，安装前会警告；已完成成片与使用记录保留。
- 公共加速源速度与可用性不保证，HTTP 响应时间不是 ping 或整包吞吐。
- 本地 2.7.9 仅供真实升级测试，不公开发布。其前后端均为 2.7.9，签名信任及更新地址与 2.8.0 相同；用户可测试 2.7.9 → 2.8.0。
