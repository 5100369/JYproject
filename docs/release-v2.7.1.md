# VideoMatrix 2.7.1

## 新增功能

- **每任务停止 / 继续**：右侧“任务”页每一行固定显示两个按钮，当前不可用的按钮禁用。运行或等待中可单独停止；停止清理后有未产出项时可以继续，并显示剩余数量。全局停止仍保留。
- **续跑原任务，只补未产出视频**：例如原目标 10 条，已保留 4 条，继续仅补 6 条。任务编号、输出列表、日志和已保留视频不清空，不覆盖旧文件。继续使用任务创建时的参数、目录、分组和随机输出/封面/变换种子；左侧后来改的参数只影响新任务。
- **多款独立进度**：按每款完成编号补剩余项，已全部产出的款跳过预检和编码。部分完成或失败时，有未产出项可继续；已保留的带警告可用视频不会重复处理，警告保留。

## 修复与优化

- 修复停止后任务行隐藏操作按钮、无法继续的问题；显示“停止中…”与“等待子进程退出”，清理结束前后端拒绝继续，连续点击也不会启动两个续跑进程。
- 预检中的核心提前注册为可停止，预检中停止不会冻结不完整的款列表，继续时不会漏掉后面的款。
- 停止时刚好完成的在途视频正确登记，进度按保留产出计数；已有文件保持不变，素材使用记录不清空。
- 停止清理期间，内置目录浏览器仍禁止删除或改名。压测与生产/续跑互斥，压测停止后需重新开始，不续跑旧样本。
- 续跑记录仅保存参数、任务编号与文件路径，不保留解码帧或旧硬件会话，全部产出后释放缓存。不添加整片重复编码或额外视频搬运。
- macOS 构建增加下载间隔、限流退避重试及 ZIP 完整性校验，避免 FFmpeg / FFprobe 下载异常造成不完整包。

## 使用边界

- **仅支持本次软件/后端运行期间继续任务。** 关闭软件或重启后端后，旧任务列表及续跑记录不恢复；已完成视频和使用记录保留。旧版本正在运行的任务不能迁移到本版继续。
- 中断中的未完成视频会重新生成，不是从中断的编码帧接着写。只有真正产出的文件才计入已完成，源素材不足或路径失效仍会提示。
- 不会重新生成已经保留的可用视频，包括带后处理警告的结果；已经产出的视频被移动或删除，也不会自动重做。
- 本地后端回归 **158 项及 97 个子测试**、前端运行测试 **24 项**、完整界面回归通过，包含真实编码停止后补齐、原文件哈希不变、素材使用记录、多款补缺、停止清理互斥、重复点击拦截及深浅色检查。

Mac 包未进行 Apple 开发者签名及公证，完整桌面使用仍需 Mac 实机反馈。升级保留素材、参数和使用记录；本版不包含实验扫描/治理界面。
